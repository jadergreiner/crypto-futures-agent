Acoes recomendadas para Project Manager — M2-025.13

1) Verificar status local (git)

# Mostrar alterações
git status --short

# Revisar diff rapidamente
git --no-pager diff --name-only HEAD

2) Commitar mudanças (assumindo branch local main)

# Adicionar all e commitar com formato padrao

3) Push para remote main

git push origin main

4) Passos pós-push
- Confirmar PR/merge se houver política (aqui assumimos push direto)
- Atualizar trackers/boards com status CONCLUIDO
- Notificar PO/SA/QA/SE/TL via canal apropriado com resumo curto
